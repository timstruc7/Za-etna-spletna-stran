# SmartDiet – Vite + React prototip

## Zagon
1. Razširi ZIP in odpri mapo `SmartDiet-Vite` v VS Code.
2. V VS Code izberi Terminal > New Terminal.
3. Zaženi `npm install`.
4. Nato zaženi `npm run dev`.
5. Odpri naslov, ki se izpiše v terminalu (običajno http://localhost:5173).

## Funkcionalnosti
- Začetna stran in pregled prehranskih nastavitev.
- Iskanje po črtni kodi prek Open Food Facts API.
- Demo izdelki, ki delujejo tudi brez API iskanja.
- Podatki o sestavinah in hranilnih vrednostih.
- Profil z alergijami in prehranskimi preferencami.
- Opozorila ob zaznanem ujemanju z izbranimi alergeni.
- Zgodovina pregledanih izdelkov.
- Shranjevanje profila in zgodovine v localStorage.
